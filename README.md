# 📱 Flutter Bluetooth Game Rehab App

Flutter 기반으로 개발된 블루투스 연동 재활 게임 앱입니다. 외부 센서 장치로부터 수집된 실시간 데이터를 활용하여 사용자가 다양한 미니게임을 통해 재활 훈련을 할 수 있도록 구성되어 있습니다.

## 🧩 주요 기능

- **자동 블루투스 연결**
  - 특정 장치(BR14_2052)를 자동 검색 및 연결
  - 실시간 센서 데이터 수신 (자이로, 가속도, 압력 등)
- **게임별 센서 기반 제어**
  - 기기 기울임, 손가락 압력 등을 게임 조작에 활용
- **3가지 미니 게임 탑재**
  - 벽돌깨기, 비행기 슈팅, 테트리스
- **각 게임별 설정 화면 제공**
  - 난이도 및 속도 조절 가능
- **Flutter 로깅 시스템 구축 (`logger.dart`)**

---

## 🎮 포함된 게임

### 1. 벽돌깨기 게임 (Brick Breaker)
- **조작 방식**: 기기를 좌우로 기울여 패들 이동
- **목표**: 모든 벽돌을 제거하여 클리어
- **설정**: 공의 속도, 패들 이동 속도 조절

### 2. 비행기 슈팅 게임 (Galaga 스타일)
- **조작 방식**: 기기를 기울여 비행기 이동
- **목표**: 적기 회피 및 타격
- **설정**: 이동 속도, 적 생성 속도 조절

### 3. 테트리스
- **조작 방식**:
  - 기기 기울이기로 좌우 이동
  - 손가락 압력으로 블록 회전
- **목표**: 줄을 채워 점수 획득, 게임 종료 전까지 최대 점수 도달
- **설정**: 낙하 속도, 좌우 이동 반응 속도 조절 가능

---

## 📡 센서 입력 항목

- `roll`, `pitch`, `yaw`: 회전 값
- `accx`, `accy`, `accz`: 가속도
- `pressure1`, `pressure2`: 손가락 압력

이러한 값들은 각 게임의 제어 입력으로 사용되며, `Stream<List<double>>` 형식으로 전달됩니다.

## 📁 주요 파일 구조

| 파일명                              | 설명                          |
| -------------------------------- | --------------------------- |
| `main.dart`                      | 앱 시작점, Bluetooth 연결 화면으로 진입 |
| `bluetooth_screen.dart`          | 블루투스 연결 및 센서 데이터 처리         |
| `game_list_screen.dart`          | 게임 선택 화면                    |
| `brick_breaker_game_screen.dart` | 벽돌깨기 게임 화면                  |
| `galaga_game_screen.dart`        | 비행기 슈팅 게임 화면                |
| `tetris_game_screen.dart`        | 테트리스 게임 화면                  |
| `*_game_setting_screen.dart`     | 각 게임의 설정 UI (속도, 난이도 등)     |
| `logger.dart`                    | 앱 전역 로그 출력 도구 구성            |
